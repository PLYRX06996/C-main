now in every directory there are two default locations:
./ --> which indicates current working directory.
viz by doing "cd .", we will be in the same directory.

- another location is ../ --> which indicates a directory above or higher or the directory in which current directory resides in.
viz. by doing "cd .." we will be moved to the direcotory above
